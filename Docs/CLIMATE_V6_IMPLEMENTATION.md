# V6 温度与改装实装说明

本次基于 `ENVIRONMENT_TEMPERATURE_AND_GLACIER_SEASON_DESIGN.md` 实装；环境温度、体温均直接储存摄氏度，不再使用旧偏移值。炉内加工温度保持独立。

## 配置入口与默认值

- `Assets/Resources/Config/ClimateConfig.asset`：首次冰层季按确认规则在第11天开始，持续24天，第34天为最后一天，第35天恢复温和季。设为0可禁用自动开始，代码仍可通过 `StartGlacierSeason()` 触发。没有自行增加季节循环周期。上一试行版尚未开始的第25天默认排期会在载入时修正；已开始或手动触发的季节不重启。
- 同一资产的 `connections`：8条显式连接，每条包含唯一ID、两端地点、两张方向卡ID。运行时卡牌按绑定查询，不解析中文名称，也不按两端地点合并连接，因此以后可配置同地点之间的不同通道。
- 地点 `PlaceData`：面积复用 `maxCoord`（`minCoord=0`），温度、隔热、昼夜/季节影响率、改装支持标记、材料掉落均可配置。
- 三个舱室隔热等级2；浅层岩穴、遇难者大厅、最后庇护所等级1。水域才显示牵引绳；室内才显示隔热棉；当前9个地点均支持防水电缆。
- 三舱新世界初始防水电缆各自随机200～600耐久；其余地点未安装。存档保留实际耐久，不重新随机。
- 盐的来源：将1张盐水放入点燃的野炊营火，加热15分钟得到1张盐；熄火时不加工。产出的盐留在营火内容物槽，不会烤焦，自热烹饪袋不能制盐。三处海域不再直接探索产盐；载入试行版世界线时也会移除对应旧掉落来源，已经持有的盐不删除。
- 已有盐水/盐卡载入时仅补齐缺失的加工组件，参数仍从卡牌表读取，不重置已有加工进度。
- 牵引绳不再支持盐填充：卡牌交互、改装按钮和拖拽补充入口均移除，制作配方仍保留盐×3。不擅自指定替代修补材料。
- 暖绒获取补充默认：浅层岩穴、遇难者大厅、最后庇护所各增加3组一次性掉落，每组3个、权重10；深度探索每次2个，种群初始/上限12、每回合恢复1、采集减少6。这部分仍为暂定可调值。

## UI与存档

- 环境窗口增加“改装”按钮，进入原详情窗口的“改装”标签；切换“信息”可查看地点详细温度来源。通道详情也有同样标签。
- 新UI复用原像素字体、按钮、窗口和选择框；内容可滚动。槽位支持拖入，也可点击“布置”；已有附件显示实际耐久与填充/拆除按钮。
- 按UI防重叠检查调整改装行的动态高度、底部操作区和8像素间距，覆盖320/375/430宽度。地点按钮采用“探索／深探／完成”和“改装”短标签，完整探索说明保留在悬停提示；通道动作栏按可视区域适配字号，过多操作仍可横向滚动。
- 双向通道只有一个附件袋和一个浮标对象，两个UI视图读同一对象；每回合只结算一次。冰封条0时隐藏，100处有封锁刻度，封锁时增加冰色外框。
- 新玩法存档结构版本为6。旧世界线保留列表和删除入口，显示“该世界线不兼容此版本”；禁止读入、复制和分享，不自动删除。新建世界线不受影响。
- 验证工具 `Tools/Climate/Apply V6 configuration and UI` 可重建目标资产。会按本次策划值覆盖目标地点、体温、配方与UI，手工调参后不要无意重跑此菜单。
