# 环境温度、体温与冰层季系统策划案

版本：V1.0 数值基线稿  
适用版本：第六版及后续版本  
结算周期：15分钟/回合

## 1. 设计目标

1. 地点环境温度会受到自然温度、昼夜、季节、地点面积、隔热和热源共同影响。
2. 冰层季即使准备充分，也需要持续消耗燃料、融冰材料和装备耐久，但不会强迫玩家放弃基地搬迁。
3. 地点面积直接沿用最大坐标；当前最小坐标固定为0，因此地点面积等于 `maxCoord`。
4. 所有地点始终使用“环境温度”这一名称。室内、室外、水域和洞穴只改变参数，不改变状态名称。
5. 麦麦体温使用真实摄氏度。炉内加工温度继续作为独立系统，不与环境温度混用。

## 2. 核心名词

| 名称 | 含义 |
| --- | --- |
| 地点面积 `A` | 等于地点最大坐标 `maxCoord`，当前典型值为15、20、50、60 |
| 当前环境温度 `T` | 地点此刻的实际环境温度，单位℃ |
| 自然环境温度 `Tn` | 没有人工热源时，地点最终会趋近的温度 |
| 环境热量 `Q` | 热源每15分钟向整个地点提供的热量点 |
| 隔热等级 `L` | 0～5级，降低地点与自然环境之间的温度交换 |
| 有效环境温度 `Te` | 麦麦所在地的环境温度加上附近热源的局部取暖值 |
| 体温 `Tb` | 麦麦核心体温，初始36.5℃ |

## 3. 环境温度规则

### 3.1 自然环境温度

每回合计算：

`Tn = 地点基础温度 + 冰层季修正 × 季节影响率 + 昼夜修正 × 昼夜影响率 + 事件修正`

地点推荐初始参数如下。该表是第六版启用温度系统时的目标值；现有地点资产中部分温度低于0℃，若不调整，将在非冰层季持续触发通道结冰。

| 地点 | 面积 | 基础温度 | 初始隔热 | 季节影响率 | 昼夜影响率 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 动力舱 | 15 | 18℃ | 2 | 25% | 15% |
| 驾驶室 | 20 | 16℃ | 2 | 25% | 15% |
| 维生舱 | 15 | 20℃ | 2 | 20% | 10% |
| 飞船外壳 | 50 | 8℃ | 0 | 100% | 100% |
| 浅层岩穴 | 15 | 6℃ | 1 | 45% | 20% |
| 珊瑚礁海域 | 60 | 14℃ | 0 | 100% | 100% |
| 遇难者大厅 | 50 | 4℃ | 1 | 50% | 20% |
| 织光藻墓园 | 60 | 12℃ | 0 | 100% | 100% |
| 最后庇护所 | 15 | 10℃ | 1 | 35% | 15% |

### 3.2 隔热等级

| 隔热等级 | 隔热率 | 剩余温度交换 | 定位 |
| ---: | ---: | ---: | --- |
| 0 | 0% | 100% | 完全暴露的水域或外部区域 |
| 1 | 20% | 80% | 天然洞穴、临时遮蔽或严重破损空间 |
| 2 | 35% | 65% | 三个飞船舱室的初始隔热水平 |
| 3 | 50% | 50% | 修复后的舱室或完成一次隔热升级的地点 |
| 4 | 65% | 35% | 完整舱室或完成一次隔热升级 |
| 5 | 80% | 20% | 最高等级保温地点 |

- 隔热等级不能低于0或高于5。
- 室内地点最多铺设一份隔热棉，使地点隔热等级+1；已有隔热棉时不能重复铺设。
- 隔热只降低自然环境的影响，不削减热源产热。

### 3.3 每回合温度变化

每15分钟按以下顺序计算：

1. `自然交换 = (Tn - T) × 0.08 × (1 - 隔热率)`
2. `热源升温 = 地点内热源总热量 Q ÷ 地点面积 A`
3. `环境温度变化 = Clamp(自然交换 + 热源升温, -4℃, +4℃)`
4. `新环境温度 = 当前环境温度 + 环境温度变化`

说明：

- 无隔热地点每回合消除8%的温差，约2小时消除一半温差。
- 5级隔热地点每回合只消除1.6%的温差，约10.75小时消除一半温差。
- 单回合最多变化4℃，防止加载、事件或多热源导致温度瞬间跳变。
- 热源停止后，地点温度逐步回落到自然环境温度，不会瞬间恢复。

### 3.4 热源数值

| 热源 | 环境热量/15分钟 | 局部半径 | 最近处取暖值 | 备注 |
| --- | ---: | ---: | ---: | --- |
| 野炊营火 | 18 | 6 | +12℃ | 主要取暖设施 |
| 燃料炉 | 36 | 4 | +8℃ | 炉内加工温度仍单独计算 |
| 燃料蒸馏器 | 12 | 3 | +4℃ | 工作时产热 |
| 燃料发电机 | 16 | 3 | +5℃ | 工作时产热 |
| 点燃的氧烛 | 3 | 2 | +2℃ | 小型应急热源 |

局部取暖线性衰减：

`局部取暖值 = 最近处取暖值 × Clamp01(1 - 麦麦与热源距离 ÷ 局部半径)`

- 多个热源的环境热量相加。
- 多个局部取暖值相加，但局部取暖总值最多为+15℃。
- 热源卡在布置或建造时记录麦麦当前坐标；旧存档中的热源默认位于地点坐标中点。
- 热源的基础燃料消耗继续使用现有规则；冰层季不直接增加每回合燃料扣除。外界更冷会迫使热源运行更久，从而自然增加总消耗。

### 3.5 热平衡示例

在自然环境温度-20℃时：

| 场景 | 长期稳定环境温度 |
| --- | ---: |
| 面积15、3级隔热、1个营火 | 约10℃ |
| 面积15、3级隔热、1个燃料炉 | 约40℃，存在过热风险 |
| 面积60、4级隔热、1个燃料炉 | 约1.4℃ |
| 面积60、4级隔热、燃料炉+营火 | 约12.1℃ |
| 面积60、5级隔热、1个燃料炉 | 约17.5℃ |

在自然环境温度-30℃时，面积60、5级隔热、燃料炉+营火可稳定在约26.3℃。因此大型地点要么提高隔热，要么维持多个热源；小型地点更容易升温，但也更容易因强热源过热。

### 3.6 作物与环境温度

作物只读取其所在地点的**当前环境温度 `T`**，不读取麦麦受到局部热源影响后的有效环境温度 `Te`。因此站在营火旁只会给麦麦取暖，不会让整个地点的作物凭空升温；热源只有通过“环境热量”抬高地点温度后，才会影响作物。

#### 温标与配置迁移

- `CardConfig.xlsx` 中现有的 `PlantTempreture` 六个数值本来就是摄氏度，顺序为：`舒适下限_舒适上限_生长下限_生长上限_存活下限_存活上限`。
- 环境温度改为摄氏度直存后，作物配置**不做减200或乘0.1换算**。
- 环境温度状态的 `normParam` 必须改为0；作物读取当前值时不能再次执行 `-200`。
- 新世界直接使用摄氏度数据。按照本案的旧世界线不兼容规则，不为旧存档中的200制环境温度制作自动迁移。
- 配置必须满足：`存活下限 ≤ 生长下限 ≤ 舒适下限 ≤ 舒适上限 ≤ 生长上限 ≤ 存活上限`。导表时若不满足则报错，不进入游戏。

#### 每15分钟结算

环境温度先完成本回合变化，作物再使用变化后的温度结算。所有上下限均为**包含边界**。

| 当前环境温度 | 生长速度 | 生存压力变化 |
| --- | ---: | ---: |
| 舒适区间内 | 基础生长速度×1.2 | -2 |
| 生长区间内、舒适区间外 | 基础生长速度×1.0 | -2 |
| 存活区间内、生长区间外 | 0 | -1 |
| 超出存活边界不超过5℃ | 0 | +1 |
| 超出存活边界超过5℃ | 0 | +2 |

- 每株作物新增生存压力，范围0～8，初始为0。
- 生存压力最低为0；达到8时作物死亡，并沿用该作物现有的死亡产物。
- 轻度致死温度连续暴露8回合，即2小时后死亡；极端致死温度连续暴露4回合，即1小时后死亡。
- 回到可生长温度后需要逐步恢复，不再像旧逻辑一样一回合清空全部死亡进度。
- 压强不合适时该回合不生长，并产生+1压力。若温度与压强同时不合适，取两者较高的压力增量，不相加。
- 成熟作物仍参与温度压力结算，不能依靠成熟状态永久免疫冰层季。

#### 第六版推荐作物温区

| 作物 | 舒适区间 | 生长区间 | 存活区间 | 基础生长/回合 | 设计定位 |
| --- | --- | --- | --- | ---: | --- |
| 水壶兰 | 12～26℃ | 5～32℃ | -5～40℃ | 0.5 | 常温高产作物，冰层季必须维持地点供暖 |
| 四角菱 | 4～16℃ | -2～24℃ | -10～32℃ | 0.7 | 耐寒粮食作物，初临期仍可生产，极寒期需要最低限度供暖 |

## 4. 冰层季

首次冰层季从世界第11天开始。冰层季总长24天，分为三阶段，第34天结束，第35天恢复温和季。下表日期为季内天数；对应世界日期为11～16、17～28、29～34天。

### 4.1 季节温度修正

| 阶段 | 日期 | 每日基础修正 |
| --- | --- | --- |
| 初临期 | 第1～6天 | -2、-4、-6、-8、-10、-12℃ |
| 极寒期 | 第7～18天 | 基础-18℃，每天再抽取天气修正 |
| 回暖期 | 第19～24天 | -15、-12、-9、-6、-3、0℃ |

极寒期每日天气：

| 天气 | 概率 | 额外修正 |
| --- | ---: | ---: |
| 稳定严寒 | 50% | 0℃ |
| 寒潮 | 30% | -4℃ |
| 极端寒潮 | 20% | -8℃ |

同一天的天气修正固定，不随存读档重抽。

### 4.2 昼夜温差

以下关键时间点之间线性插值：

| 时间 | 昼夜修正 |
| --- | ---: |
| 00:00 | -5℃ |
| 04:00 | -6℃ |
| 08:00 | -2℃ |
| 12:00 | +3℃ |
| 16:00 | +1℃ |
| 20:00 | -2℃ |

昼夜修正和冰层季修正分别乘地点对应的影响率。飞船舱室仍会变冷，但变化远小于露天水域。

## 5. 麦麦体温

### 5.1 基础规则

- 初始及目标体温：36.5℃。
- 体温结算范围：30～42℃。
- 有效环境温度：`Te = 当前环境温度 + 附近热源取暖总值`。
- 水域地点的冷热交换倍率为1.35。
- 睡觉或原地休息时的寒冷交换倍率为1.25；与水域倍率相乘。

每15分钟：

1. 若 `Te < 10℃`：
   `降温 = Min(0.8, (10 - Te) × 0.02) × 水域倍率 × 休息倍率`
2. 若 `10℃ ≤ Te ≤ 30℃`：
   体温以每回合最多0.15℃向36.5℃恢复。
3. 若 `Te > 30℃`：
   `升温 = Min(0.6, (Te - 30) × 0.015) × 水域倍率`

### 5.2 体温状态与效果

| 体温 | 状态 | 每15分钟效果 | 行动影响 |
| --- | --- | --- | --- |
| <32℃ | 失温危急 | 健康-2，饥饿-1.5 | 移动与探索时间+50% |
| 32～34.9℃ | 严重寒冷 | 健康-0.5，饥饿-1 | 移动与探索时间+25% |
| 35～35.4℃ | 寒冷 | 饥饿-0.4 | 移动与探索时间+10% |
| 35.5～37.5℃ | 正常 | 无负面效果 | 无 |
| 37.6～38.4℃ | 炎热 | 水分-0.4 | 无 |
| 38.5～39.9℃ | 严重炎热 | 健康-0.5，水分-1 | 移动与探索时间+15% |
| ≥40℃ | 过热危急 | 健康-2，水分-2 | 移动与探索时间+40% |

### 5.3 冬季与夏季装备

- 冬季装备只拦截负体温变化。
- 夏季装备只拦截正体温变化。
- 保温服属于冬季身体装备。
- 后续夏季装备沿用同一规则反向处理，不增加湿度、材质和叠穿模拟。

所有旧体温直接变化值按 `旧值 × 0.1℃` 迁移。例如旧规则中的体温+20改为+2℃。

## 6. 通道冰封

### 6.1 双向通道共享连接

去程卡和回程卡不是两条独立通道，而是同一条“通道连接”的两个入口视图。每条双向连接只保存一份共享状态：

- 通道连接ID；
- 两端地点；
- 冰封值；
- 一个融冰浮标附件位；
- 已布置浮标的卡牌数据和耐久。

当前通道配对如下：

| 通道连接ID | A端 | B端 | 水域连接 | 显示浮标槽 |
| --- | --- | --- | --- | --- |
| Cockpit-PowerCabin | 驾驶室 | 动力舱 | 否 | 否 |
| Cockpit-LifeSupportCabin | 驾驶室 | 维生舱 | 否 | 否 |
| Cockpit-CoralCoast | 驾驶室 | 珊瑚礁海域 | 是 | 是 |
| CoralCoast-PhosphorTomb | 珊瑚礁海域 | 织光藻墓园 | 是 | 是 |
| CoralCoast-SpaceshipOuterHull | 珊瑚礁海域 | 飞船外壳 | 是 | 是 |
| PhosphorTomb-ShallowGrotto | 织光藻墓园 | 浅层岩穴 | 是 | 是 |
| ShallowGrotto-VictimsHall | 浅层岩穴 | 遇难者大厅 | 是 | 是 |
| VictimsHall-LastSanctuary | 遇难者大厅 | 最后庇护所 | 是 | 是 |

- 两张方向卡必须通过显式的通道连接ID绑定，不使用卡牌名称猜测，也不只用起终点临时拼接。
- 通道连接ID在配置中唯一；以后即使两个地点之间存在多条通道，也可以分别保存状态。
- 双向卡牌读取同一个冰封值。任意一侧除冰，另一侧显示的冰封值同步变化。
- 一个共享连接每回合只结算一次，不能让去程卡和回程卡分别结算，否则冰封和浮标损耗会翻倍。

### 6.2 冰封值

- 所有通道连接拥有冰封值，范围0～200，初始0。
- 两端地点均不是水域的连接不会积累冰封，冰封值固定为0。
- 连接只有一端是水域时，使用水域端的环境温度结算。
- 连接两端都是水域时，使用两端环境温度中的较低值结算。
- 判断使用玩家界面显示的真实摄氏度，不使用内部偏移值。

每15分钟：

| 环境温度 | 冰封值变化 |
| --- | --- |
| <0℃ | 随机增加2～10，包含2和10 |
| =0℃ | 不变 |
| >0℃ | `-Clamp(Ceil(环境温度 ÷ 2), 1, 10)` |

- 随机结果由 `Random.Range(2, 11)` 产生。
- 冰封值最终限制在0～200。
- 平均每回合增加6点时，约4小时10分钟达到100点封锁，约8小时20分钟达到200点。
- 在5℃环境下，从100点自然融化约需8小时20分钟；10℃约5小时；20℃约2小时30分钟。

### 6.3 通行状态

| 冰封值 | 状态 |
| --- | --- |
| 0～99.9 | 正常通行 |
| 100～200 | 已冰封 |

已冰封时：

- “通过/前往”按钮不可交互，提示“通道已被冰封，需要用武器或工具除冰”。
- “移至附近”仍可使用。
- 卡牌显示冰层覆盖边框。
- 冰封值降到100以下后立即恢复通行和普通边框。

### 6.4 手动除冰

所有除冰交互要求麦麦距离通道不超过3坐标。

| 方式 | 时间 | 冰封值 | 额外消耗 |
| --- | ---: | ---: | --- |
| 用手除冰 | 15分钟 | -7 | 体温-0.5℃ |
| 普通工具或武器 | 15分钟 | -30 | 对应卡牌耐久-1 |
| 钢锤强力除冰 | 5分钟 | -50 | 钢锤耐久-1 |

- 普通除冰适用于所有 `Tool` 或 `Weapon` 类型卡牌。
- 自热烹饪袋、凝胶装瓶器属于明确排除项：不显示选项，拖拽到通道也不响应。
- 行动耗时期间冰封仍正常结算；行动结束后再扣除冰封值。
- 工具因本次交互损坏时，除冰效果仍然生效。

制作配方，由“基建”解锁：

- 时间：30分钟；
- 材料：韧性胶管×2、盐×3、暖绒×2；
- 产出：融冰浮标×1。

### 7.2 布置

- 只要通道连接至少有一端是水域，该连接就拥有1个共享融冰浮标槽。
- 去程卡和回程卡都显示这个槽，但它们只是同一个共享附件位的两个UI视图，不能分别容纳卡牌。
- 将未布置的融冰浮标拖到通道卡牌或专用槽后，切换为已布置形态。
- 从任意一侧布置时，浮标进入通道连接持有的附件位；另一侧立即显示同一张已布置浮标及同一耐久值。
- 每条双向通道连接最多布置1个浮标，而不是每张方向卡各布置1个。
- 从任意一侧填充浮标，修改的都是共享浮标耐久。
- 浮标归零销毁时，共享附件位清空，两侧UI同时恢复为空槽。
- 已布置后不能直接拖出，只能持续维护直至耐久归零销毁。

### 7.3 每回合效果

| 条件 | 耐久消耗 | 冰封值变化 |
| --- | ---: | ---: |
| 通道冰封值为0 | -0.2 | 0 |
| 通道冰封值大于0 | -1.0 | -15 |

- 冰封增长、自然融化和浮标融冰先求和，再统一限制到0～200。
- 平均冰封增长6点时，浮标净减少约9点/回合。
- 满耐久浮标在持续有冰状态下可工作864回合，即9天。
- 无冰状态下理论寿命为4320回合，即45天。
- 耐久归零后自动销毁，下一回合起不再融冰。

### 7.4 填充

填充不消耗时间，耐久满时不可使用：

| 材料 | 耐久恢复 |
| --- | ---: |
| 盐×1 | +150 |
| 暖绒×1 | +200 |

恢复值不能超过864。资源可直接拖到浮标上，也可通过“使用盐填充/使用暖绒填充”按钮执行。

### 7.5 盐的获取

- 将1张盐水放入点燃的野炊营火，加热15分钟获得1张盐。
- 熄火时不加工；产物盐留在营火内容物槽，不继续烧焦。
- 不通过海域探索直接掉落盐，也不使用自热烹饪袋制盐。
- 盐可填充融冰浮标，但不能补充牵引绳耐久。

## 8. 保温服

### 8.1 卡牌数据与配方

| 字段 | 数值 |

| 耐久上限 | 1440 |

- 材料：暖绒×4、纤维×12、燃素×6；
- 产出：保温服×1。

### 8.2 保温效果

当任意来源即将使体温下降时：

- 15%的降温作用于麦麦；
- 85%的降温由保温服吸收；
- 每吸收1℃消耗10耐久；
- 耐久不足时，无法吸收的部分重新作用于体温；
- 耐久归零后保温服损坏并销毁。

例：本回合原本体温-0.6℃，保温服耐久充足，则实际体温-0.09℃，耐久-5.1。

详细推演：

| 水域环境温度 | 无装备降温/回合 | 保温服后降温/回合 | 耐久消耗/回合 | 满耐久连续支撑 |
| ---: | ---: | ---: | ---: | ---: |
| 0℃ | -0.27℃ | -0.041℃ | 2.30 | 约6.5天 |
| -10℃ | -0.54℃ | -0.081℃ | 4.59 | 约3.3天 |
| -20℃ | -0.81℃ | -0.122℃ | 6.89 | 约2.2天 |
| -30℃ | -1.08℃ | -0.162℃ | 9.18 | 约1.6天 |

### 8.3 修补

修补耗时3分钟，满耐久时不可执行：

| 材料 | 耐久恢复 |
| --- | ---: |
| 纤维×1 | +30 |
| 暖绒×1 | +260 |

修补过程中保温服仍保持装备状态；时间结算产生的降温正常发生。

## 13. 存档兼容策略

- 本系统启用新的玩法存档结构版本 `WorldSchemaVersion`；它与分享文件的封装格式版本和展示用游戏版本号分开管理。
- 缺少通道连接状态、地点改装状态、真实体温或新环境温度数据，且没有专门迁移器的旧世界线，标记为不兼容，不尝试带默认值强行读取。
- 世界线列表仍读取旧世界线的名称、模式、最后时间和地点等索引信息，但状态位置显示固定文案：“该世界线不兼容此版本”。
- 不兼容世界线的“读取”按钮不可交互；不能复制为新世界线，也不能进入游戏。
- 玩家仍可选中并通过管理菜单删除不兼容世界线；删除前沿用正常世界线的二次确认流程。
- 不兼容世界线不会被自动删除，也不会阻止玩家创建、导入或游玩新的兼容世界线。
- 新世界创建时写入当前 `WorldSchemaVersion`，并完整初始化环境温度、隔热、地点改装、通道连接、冰封、浮标附件和作物生存压力状态。
- 同一玩法结构版本内继续正常存读档；未来若存在安全迁移方案，再为对应旧版本单独增加迁移器。
- 环境温度和体温在配置、运行时、存档及界面中均直接使用℃，不再保留200制内部偏移。
- 炉内 `TemperatureComponent` 保持原加工温度和配方区间，不与环境温度存档混用。

## 14. 验收用例

1. 面积15和面积60的地点使用同一营火时，前者每回合升温值应为后者的4倍。
2. 两个相同地点分别为0级和5级隔热，关闭热源后5级地点回落明显更慢。
3. 极寒期露天水域在夜间低于0℃，通道开始积累冰封；温度回到0℃时停止变化，高于0℃时自然融化。
4. 冰封值从99增加到100时通道立即封锁，从100降低到99时立即恢复。
5. 融冰浮标在无冰时每回合只消耗0.2耐久；有冰时共消耗1耐久并减少15冰封值。
6. 普通工具、钢锤、排除工具分别触发普通除冰、强力除冰和无交互。
7. 保温服完整、耐久不足和耐久归零三种情况下，体温与耐久分摊正确。
8. 暖暖贴一次制作3个，使用后不允许体温超过37.5℃。
9. 牵引绳只缩短地点内水域移动时间，不影响探索和跨地点通道时间。
10. 存读档后环境温度、隔热等级、通道冰封、已布置浮标、地点改装和装备耐久完全一致。
11. 从去程侧布置或填充融冰浮标后，回程侧显示同一浮标和相同耐久；整条连接每回合只扣除一次浮标耐久并只结算一次冰封。
12. 非水域地点完全不显示牵引绳改装；非室内地点完全不显示隔热棉改装。
13. 三个舱室的新世界初始电缆耐久均在200～600内，存读档后数值不重抽；电缆归零时地点失去电缆并断开设备。
14. 旧结构世界线显示“该世界线不兼容此版本”，不能读取但可以删除，且不影响创建新世界线。
15. 环境温度恰好等于任一作物温区的上限或下限时，该边界仍属于对应区间，不会被误判为受损。
16. 水壶兰在12℃和26℃时按1.2倍生长，在5℃和32℃时按1倍生长，在-5℃和40℃时休眠但不增加生存压力。
17. 作物在轻度致死温度连续8回合死亡，在超出存活边界超过5℃的温度连续4回合死亡；中途恢复到安全温度时压力逐步下降而非立即清零。
18. 麦麦仅靠近局部热源但地点环境温度未变化时，作物温度状态不变；热源抬高地点环境温度后，作物才切换温度状态。
