# UI 方案预览

新增：[世界线入口页 B 版补充设计稿](worldlines/index.html)。仅展示世界线及最新进度，“载入游戏”进入保存记录页；次级操作收进管理菜单。

打开 `index.html`，可并排比较 A–D，并切换保存记录、创建世界线、设置三个页面，点击图片放大。

| 方案 | 保存记录布局 | 适合的操作习惯 |
|---|---|---|
| A 档案列表 | 单窗口、对齐的信息列、底部操作栏 | 经常比较时间点，保存记录较多 |
| B 航行日志 | 按游戏日期分组，选中记录展开 | 先回忆哪一天，再找具体时间点 |
| C 桌面双窗口 | 左侧世界线窗、右侧历史窗 | 频繁切换世界线，延续游戏的桌面窗口习惯 |
| D 保存点卡片 | 地点图标、三列卡片、底部操作栏 | 优先看地点图像辨认记录 |

共同约束：使用项目的 CustomWindow、TopBar、CustomWindowButton、滚动条、UI_Panel、UI_HoveredFrame、像素字体和地点图片；默认按钮带边框；#64DEAE 仅用于选中及主要操作；不显示角色状态。

每版有三张 1920×1080 Unity 渲染图，使用相同的示例存档信息。此阶段用于选择方案，没有绑定真实数据、输入或存档操作，也没有替换正式 SaveHub。创建页没有加入人物特性功能。

配套静态预制体及一次性导出脚本已归档到 `authoring-archive.zip`，避免方案样本留在 Unity 资源和编译目录中。压缩包保留原始相对路径，确需重新制作方案时可恢复；正式界面使用 `Assets/Resources/Prefabs/UI/SaveHub.prefab`。`render-check.txt` 为文字高度检查结果，十二张图片还经过逐张目视检查。
