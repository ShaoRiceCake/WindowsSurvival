# 设置窗口设计稿

这是独立布局提案，未改动 Unity 脚本、Prefab、场景或游戏数据。打开 `index.html` 查看交互预览。

| 方案 | 窗口尺寸（1440 宽设计画布） | 布局 |
| --- | --- | --- |
| A 双栏面板 | 1044 × 574 | 左侧时间线与最近保存；右侧继续、保存、读取；右下次级退出操作 |
| B 侧栏设置（推荐） | 1032 × 574 | 固定左侧分类；右侧时间线、保存摘要、保存/读取；底部次级退出与主要继续 |
| C 紧凑菜单 | 802 × 576 | 横向分类；紧凑信息头；继续占一行，保存/读取并排，退出在底部 |

三版均不展示角色状态。读取保存点先进入列表，退出通过保存并退出确认；此处流程仅为演示，不替换现有保存记录界面。设置子页用于展示同一结构容纳控件的方式，不承诺新增显示类功能。

复用 `../motion/assets/` 的 `UI_HoveredFrame.png`、`UI_Panel.png`、边框遮罩、`pixel.ttf`、`驾驶室.png`；标题齿轮为临时矢量占位，实装时使用项目设置图标。后续实装须继续复用休息窗口的 ModalBackdrop，设计稿为便于比较使用纯暗背景。

## 交互规格

- 悬停 140 ms：仅原有边框提亮，不增添第二圈、不反转底色。
- 按下 70 ms：按钮文字下沉 1 px；不改变点击区域。
- 主要动作和当前分类使用 `#64DEAE`；次级退出按钮缩小、降低明度。
- 分类切换 140 ms 淡入，外框尺寸不变；设置项增加时内容区滚动，底部动作保留。
- 保存演示显示 1 秒进度，再显示 2.4 秒完成提示。
- 长名称自动换行；提供“试用长名称”开关。

## 图片与检查

导出图片位于 `output/playwright/settings-A.png`、`settings-B.png`、`settings-C.png`、`settings-B-sound.png`（相对仓库根目录）。
设计源使用浏览器渲染并目视检查。字体已加载，三版游戏页未检测到文本溢出。此验证针对设计稿，不是 Unity Play Mode 验收。

交互检查：三版切换至长名称后仍无溢出；手动保存按钮悬停前后背景保持 `rgb(17,17,17)`，边框从 `rgb(116,118,113)` 变为 `rgb(184,201,192)`；保存过渡超过 1 秒后关闭；读取打开含三条记录的列表，而非直接进入游戏。
