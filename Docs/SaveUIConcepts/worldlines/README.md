# 世界线入口页 · B 版补充设计稿

预览：http://127.0.0.1:8876/worldlines/（服务器根目录为上一级 SaveUIConcepts）。

此目录保留可交互设计稿；对应入口布局及两步载入流程已接入 Unity 的正式 SaveHub.prefab。浏览器演示只修改页面内的数据，不接触真实存档。引擎验收证据另见 `../../SaveValidation/Worldlines/`。

- 左侧每个条目对应一个世界线 ID，按最近游玩排序；同名世界线仍是独立条目。此页不列出保存点。
- 右侧显示名称、模式，以及最新保存点的地点与游戏时间；另显示累计游玩、保存记录数、最近游玩时间。不显示角色状态。
- 唯一主操作为“载入游戏”：进入所选世界线的保存记录页面，再选择记录并点击读取。入口页不直接进入游戏。
- 复制、分享、改名、删除收进“管理世界线”菜单；删除与其他操作分隔，并二次确认。
- 延用现有 UI_HoveredFrame、UI_Panel、地点图标与像素字体。悬停只改变原边框颜色；不反色、不增加第二圈描边。按下文字下沉 1px，按钮命中区域不移动；主按钮箭头轻移。
- 空列表、普通、硬核和多世界线状态可在页面外的演示工具栏切换。硬核世界线进入记录页后只显示一个时间点。

浏览器验证：两步载入及返回、改名、删除取消、22 个独立世界线滚动、空列表、硬核单记录；1440 / 780 / 390 像素宽度无页面横向溢出。窄屏页面允许纵向滚动。此处不代表 Unity Play Mode 验收。
