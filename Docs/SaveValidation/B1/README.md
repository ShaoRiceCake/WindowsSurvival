# B1 航行日志实装

本轮以 B 版时间轴布局和 B1 边框反馈替换正式 SaveHub 的保存记录、创建世界线及设置页。

- 按钮使用现有 CustomWindowButton 派生模板，底色与文字分离；单层 UI_HoveredFrame 素材常驻，默认灰色，悬停提亮，选中薄荷绿。不会叠第二圈边，也不会整块反色。
- 交互组件为 SaveHubButton，采用非缩放时间驱动颜色渐变和 1px 轻压；其他游戏窗口的按钮行为不变。
- 时间轴记录按游戏日期显示，选择后展开地点、游戏时间、实际保存时间和游玩时长。自动记录可保留为手动记录；不显示角色当前状态。
- 创建页包含名称、随机、两种模式和教程开关；仍通过 CompleteCreation / NextCreationStep 保留未来人物特性步骤。
- 设置页由 SaveSettingRegistry 的分类与定义生成。新增 toggle、enabled、unit 扩展字段；滑条、整数加减和开关不需要重建整页即可反馈变化。
- 去掉设置作用范围、即时生效等常驻说明，保留必要的硬核模式说明、危险操作确认及短暂操作结果。
- 退出保存改为 Auto，和定时自动保存共用数量上限。旧数据的 Exit 值在读取、分享导入及后续保存时兼容为 Auto；读取时不删除文件。旧记录在后续自动保存轮换时按新规则清理。手动记录仍永久保留。
- 自动轮换始终保留本次提交的最新记录，即使系统时钟回拨，也不会出现 latestSnapshotId 指向已淘汰记录的情况。

## 验证

在独立工程副本和隔离存档目录中完成，未对真实玩家存档执行删除测试。

- `data-tests.txt`：521 条数据和命名断言，包括旧退出记录兼容、旧分享文件导入、自动轮换、手动保留、最新记录完整性。
- `build.txt`：Windows Development Player 构建结果。
- `checks.txt`：实际播放器中的界面与游戏流程检查。
- PNG：运行中的实际 SaveHub Canvas 经 Unity Camera / RenderTexture 输出。用于验证当前 Prefab 的布局和显示，不是网页稿，也不是重画 UI。批处理播放器没有可用的呈现缓冲区，因此不使用其黑色背缓冲截图作为视觉证据。

本轮未做真实鼠标逐项人工验收、原生文件选择器点击或显示模式确认超时的人手操作；播放器检查通过事件和实际数据路径执行。
