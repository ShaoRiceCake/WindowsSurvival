2026-09-18，Unity 2022.3.34f1c1。使用隔离测试工程和独立存档目录，没有使用或删除玩家存档。

## 本次行为

- 空世界线说明为「麦麦根本不存在」。
- 创建当帧禁用按钮，跨场景过渡层拦截输入，完成后淡出；重复点击不会创建多个世界线。首次点击前已初始化遮罩，避免新建 Canvas 尚未产生 Graphic depth 时穿透。
