# 四处选择切换动效

此目录记录最初的滑动选中框实现及回归验证；最终通过的悬浮边框交接效果与验证见 [SelectionHandoff](../SelectionHandoff/README.md)。

2026-09-18，Unity 2022.3.34f1c1，隔离工程 Editor Play Mode；使用项目实际 Prefab 和真实按钮事件。

- 设置分类、日志筛选、世界线列表使用原有 `UI_HoveredFrame` 切片；0.2 秒 OutQuad，单个选中框移动至目标。底栏设置沿用原有 OutBack 动效，关闭后恢复原桌面选择。
- 检查暂停时继续播放、快速连点从当前位置接续、初次显示对齐、到达目标后只有一层选中边框、框体不拦截射线、不参与布局。
- 检查 22 条世界线滚动复用、离屏框使用原有 stencil 遮罩、滚动后再选、从世界线打开保存记录、日志筛选按钮保持实例及正确过滤数据。
- 检查底栏设置实际打开游戏页、关闭和快速开关恢复此前选择；设置不混入教程解锁列表。
- `checks.txt` 包含专项结果及选中边框实际渲染像素检查。`regression-play.txt` 为现有创建、保存、读档、死亡、返回主菜单、改名、复制、删除及硬核记录流程；`regression-repository.txt` 为 527 项仓库/Prefab 检查。
- `selection-motion.mp4` 由引擎相机捕获的连续帧汇总，按记录时间间隔播放，段落首尾加停留便于查看。渲染捕获速度低于正常游戏帧率；未生成或补间动画画面。

测试使用独立临时存档，不读取或删除玩家实际存档。不涉及构建发布或外部账号。
