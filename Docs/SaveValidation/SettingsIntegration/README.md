# 设置入口、游戏操作与遮罩验证

2026-09-18，Unity 2022.3.34f1c1，隔离工程与独立测试存档目录。

## 实装

1. 游戏底栏 Settings 图标序列化绑定到设置的「游戏」页；Esc 使用同一入口。顶部 SaveButton / QuitButton 及其子对象从 GameScene 删除。
2. 保存、读取保存点、返回主菜单和退出游戏集中在设置的游戏页。读取保存点只打开当前世界线的已有记录界面，返回后恢复游戏页。
3. 游戏页、记录页、世界线详情、退出/死亡与进度层中的名称带「时间线名称：」标签。
4. 自动保存成功时右上角提示 2.5 秒再淡出；失败提示 4 秒。提示不拦截射线，不暂停游戏。
5. 进度层至少显示 0.8 秒，按实际经过时间计时；覆盖载入、手动保存、退出及失败路径。慢操作完成后无需再额外等待 0.8 秒。
6. 将休息窗口原有 Modal 提取为 ModalBackdrop.prefab，休息与 SaveHub 引用同一资产。保留黑色透明底板与射线拦截，并阻止 WindowsManager 在遮罩显示期间继续扫描底层窗口焦点。
