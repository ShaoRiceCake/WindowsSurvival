# 世界线入口页实装验收 · 2026-09-18

正式资源：`Assets/Resources/Prefabs/UI/SaveHub.prefab` 的 `Worldlines` 层级。沿用 CustomWindow、CustomWindowButton、UI_HoveredFrame、ScrollView、像素字体和 PlaceData 地点图片。固定布局与控件引用已序列化，运行时仅绑定数据和复用滚动条目。

- 每个世界线 ID 显示一个条目，摘要使用 latestSnapshotId 指向的保存点。最新地点、游戏时间、累计游玩、记录数与最近游玩可见；不显示角色状态。
- “载入游戏”进入保存记录页，再点击“读取此记录”进入游戏。普通、硬核均经过记录页，硬核禁止删除记录和转为手动记录。
- 改名、复制、分享、删除位于次级管理菜单；删除需确认。返回保留选择与滚动位置，复制后选中独立副本。
- 原边框变色、文字轻按、箭头轻移、详情与菜单淡入；不增加第二圈描边，不改变按钮底色及文字颜色。

在 Unity 2022.3.34f1c1 隔离工程中执行 **Editor Play Mode**，使用隔离保存目录。未控制用户打开的编辑器，未修改真实存档。正式场景、Prefab 和相关脚本与测试副本 SHA-256 一致，见 `asset-verification.txt`。测试入口没有重新生成 Prefab。
